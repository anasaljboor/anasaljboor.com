# Blitz SEO: 30-day sprint (start the day the PR merges)

## Target

- **Keyword:** "web developer Jordan" (with "web developer Amman" and "freelance web developer Jordan" as the 2 close variants). 3 keywords is the hard limit.
- **Why this one:** it is the highest-intent search a paying client types, it maps directly to the "Business website" and "Web app" offers, and local results are usually agencies with thin pages, which a fast page with real proof can beat. DevOps searches ("DevOps consultant Jordan") have fewer buyers; they get their own page after this sprint.
- **Page:** the home page `https://anasaljboor.com/`. It is the only page with any authority today.
- **Honest caveat:** the domain is new with few links. The skill says Blitz works best on a page already at position 5-20. Expect the first 2 weeks to be mostly indexing and brand searches; page-one movement for the local keyword is more likely around day 20-30, and only if the link work happens.
- **Unknowns:** no keyword volumes (no Ahrefs key). Check Search Console's Performance report on day 7 and switch the target if a different query is already getting impressions.
